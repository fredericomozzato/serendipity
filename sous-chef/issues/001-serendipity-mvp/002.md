# Slice 002 — Player skeleton with hardcoded videos

## Context
Slice 001 (Bootstrap) produces the Rails 8 app with Hotwire (Turbo + Stimulus), Tailwind CSS (`darkMode: 'class'`), and importmaps. This slice builds the first visible feature on top of that skeleton: a YouTube IFrame player cycled through a hardcoded tracklist via a Stimulus controller, plus a dark/light mode toggle in the navbar.

---

## Scope
- Single-page layout: video embed area, track metadata area, Next/Previous controls
- YouTube IFrame API loaded and controlled by a Stimulus controller
- Hardcoded tracklist (5 videos); autoplay on page load and on every navigation
- Dark/light mode toggle in the navbar; preference persisted in `localStorage`; no flash on reload
- No Discogs, no DB writes, no auth

---

## Files to create/modify

### `config/routes.rb`
```ruby
root "player#index"
get "/player", to: "player#index"
```

Both routes resolve to the same action so `/player` and `/` are interchangeable.

### `app/controllers/player_controller.rb` _(create)_
```ruby
class PlayerController < ApplicationController
  def index; end
end
```

### `app/views/layouts/application.html.erb` _(modify)_
- Add inline `<script>` in `<head>` that reads `serendipity_theme` from localStorage and adds `dark` class to `<html>` before first paint (prevents flash)
- Add `data-controller="theme"` to `<body>`
- Add `<nav>` containing the app name and a toggle button: `data-action="click->theme#toggle"`

### `app/views/player/index.html.erb` _(create)_
- Outer div: `data-controller="player"`, mobile-first single-column layout
- `<div id="youtube-player">` — IFrame API mounts here
- Track metadata section with Stimulus targets: `data-player-target="title"`, `data-player-target="artist"`, `data-player-target="year"`
- Previous button: `data-action="click->player#previous"`, `data-player-target="previousBtn"`, `disabled` attribute set
- Next button: `data-action="click->player#next"`

### `app/javascript/controllers/player_controller.js` _(create)_
```javascript
// Key signatures:
const TRACKS = [/* 5 objects: { id, title, artist, year } */]

static targets = ["title", "artist", "year", "previousBtn"]
static values  = { index: { type: Number, default: 0 } }

connect()              // → loadYouTubeAPI()
loadYouTubeAPI()       // appends IFrame API script once; sets window.onYouTubeIframeAPIReady
initPlayer()           // new YT.Player("youtube-player", { playerVars: { autoplay: 1 }, events: { onReady: e => e.target.playVideo() } })
next()                 // index = (index + 1) % TRACKS.length → loadTrack()
previous()             // guard: return if index === 0 → index-- → loadTrack()
loadTrack()            // player.loadVideoById(id) + updateMetadata() + updatePreviousButton()
updateMetadata()       // sets title/artist/year target textContent from TRACKS[index]
updatePreviousButton() // previousBtnTarget.disabled = index === 0
```

`loadVideoById` triggers autoplay natively via the IFrame API — no additional call needed after the initial `onReady`.

### `app/javascript/controllers/theme_controller.js` _(create)_
```javascript
// Key signatures:
connect() // no-op — theme already applied by inline head script
toggle()  // document.documentElement.classList.toggle("dark")
          // localStorage.setItem("serendipity_theme", isDark ? "dark" : "light")
```

### `spec/system/player_spec.rb`
All examples use `js: true`. A `YT` stub is injected via `page.execute_script` before each example so the Stimulus controller initializes without a real YouTube network call. Autoplay is verified indirectly via metadata state (the IFrame itself is cross-origin; playback cannot be asserted from Ruby). Theme tests do not need a stub.

| Example | Maps to scenario |
|---------|-----------------|
| `Previous button is disabled on page load` | Previous disabled |
| `page load displays the first track metadata` | Video autoplays on page load (metadata as proxy) |
| `clicking Next displays the second track metadata` | Next loads next video |
| `clicking Next enables the Previous button` | Next loads next video |
| `clicking Next then Previous restores the first track metadata` | Previous navigates back |
| `clicking Next then Previous disables the Previous button again` | Previous navigates back |
| `clicking Next from the last track wraps to the first track metadata` | Next wraps around |
| `clicking the dark mode toggle adds dark class to html element` | Toggling dark mode |
| `clicking the dark mode toggle twice removes dark class` | Toggling dark mode (idempotent) |
| `dark mode preference is restored after page reload` | Theme persists |
