<task type="auto">
  <name>Task 2: Create Docker infrastructure files</name>
  <files>

  <read_first>

  <action>
    1. Create `entrypoint.sh` at project root (per D-10):
       ```bash
       #!/bin/bash
       set -e

       # Remove stale server PID (prevents crash on container restart)
       rm -f /app/tmp/pids/server.pid

       exec "$@"
       ```
       Make executable: `chmod +x entrypoint.sh`

    2. Create `Dockerfile` at project root (per D-05, D-07, D-08):
       ```dockerfile
       FROM ruby:3.4

       RUN apt-get update -qq && \
           apt-get install -y --no-install-recommends \
             build-essential \
             libpq-dev \
             curl && \
           rm -rf /var/lib/apt/lists/*

       WORKDIR /app

       ENV BUNDLE_PATH=/usr/local/bundle

       COPY Gemfile Gemfile.lock ./
       RUN bundle install

       COPY . .

       COPY entrypoint.sh /usr/local/bin/entrypoint.sh
       RUN chmod +x /usr/local/bin/entrypoint.sh
       ENTRYPOINT ["entrypoint.sh"]

       EXPOSE 3000
       CMD ["bundle", "exec", "rails", "server", "-b", "0.0.0.0"]
       ```
       Per D-07: Single dev Dockerfile, no multi-stage.
       Per D-05: `FROM ruby:3.4`.
       Per Pitfall 6: `libpq-dev` required for `pg` gem native extension.
       Do NOT add `platform: linux/amd64` (per RESEARCH.md Open Question 1).

    3. Create `docker-compose.yml` at project root (per D-08, D-09, D-16, D-17):
       ```yaml
       services:
         web:
           build: .
           command: bash -c "bin/rails tailwindcss:build && bundle exec rails server -b 0.0.0.0"
           volumes:
             - .:/app
             - serendipity_gems:/usr/local/bundle
           ports:
             - "3000:3000"
           environment:
             - RAILS_ENV=development
             - RAILS_MASTER_KEY=${RAILS_MASTER_KEY}
             # V2: uncomment with db service below
             # - DATABASE_URL=postgresql://postgres:password@db:5432/serendipity_development
           tty: true

         # V2: uncomment to activate PostgreSQL
         # db:
         #   image: postgres:16
         #   volumes:
         #     - postgres_data:/var/lib/postgresql/data
         #   environment:
         #     - POSTGRES_PASSWORD=password

       volumes:
         serendipity_gems:
         # postgres_data:  # V2: uncomment with db service
       ```
       Per D-08: Named volume `serendipity_gems` at `/usr/local/bundle`.
       Per D-09: Port `3000:3000`.
       Per D-16: `db` service commented out with `# V2: uncomment to activate PostgreSQL`.
       Per D-17: `DATABASE_URL` commented with `# V2: uncomment with db service below`.
       Per RESEARCH.md Open Question 3: `bin/rails tailwindcss:build` runs before server start.
       INFRA-02 satisfied: zero-code-change PostgreSQL activation for V2.
       INFRA-03 satisfied: no DB service active, all state is session-based (CookieStore).

    4. Create `.dockerignore` at project root:
